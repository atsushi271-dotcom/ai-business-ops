# 公開デモの説明

全ての案件・日付・数値は架空です。実運用の成果と比較するためのデータではありません。

## 検査が確かめること

- `knowledge/*.md` の確認日がISO形式か。
- Markdownの相対リンク先が存在し、リポジトリの外へ出ていないか。
- `05_open_issues.md` と `08_ledger.md` の台帳IDに重複がないか。
- 表の列数が揃っているか。
- 現在の情報に取り消し線が残っていないか。

確認日が30日より古い場合は警告です。リンクの `#見出し` の存在、業務上の事実、外部URLの到達性は検査しません。
日付指定は、架空データを同じ条件で再現するためのオプションです。

## 手で試せる失敗例

`knowledge/05_open_issues.md` のリンクを存在しない相対パスに変えて検査すると、エラーになります。
`08_ledger.md` にある `D-001` を同じ台帳に追加しても重複エラーになります。
復元してから、週次レビューのテンプレートを生成してください。

## 扱わない処理

この公開版は広告・ショップ・クラウドへの接続や設定変更を行いません。
実運用側に存在した認証設定、BigQuery接続ラッパ、バックアップ、SQL全文は含めていません。
